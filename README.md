# MiniTodoApp 📝

A simple, modern, and responsive To-Do List web application built using HTML, CSS, and JavaScript with the help of Cursor AI.

## 🚀 Features

- ➕ **Add Tasks:** Quickly add new tasks to your list.
- ✅ **Mark as Completed:** Mark tasks as completed when you finish them.
- 🗑️ **Delete Tasks:** Remove tasks you no longer need.
- 💾 **Local Storage:** Automatically save tasks in your browser so they remain after refreshing the page.
- 🌙 **Dark Mode:** Switch between light and dark themes.
- 📊 **Task Counter:** Track total and completed tasks.
- 📱 **Responsive Design:** Works on desktop and mobile devices.
- ⚠️ **Input Validation:** Prevent adding empty tasks.

## 🛠️ Technologies Used

- HTML5 — Application structure
- CSS3 — Styling and responsive layout
- JavaScript — Application logic and interactivity
- Browser Local Storage — Persistent task storage
- Cursor AI — Code generation, debugging, and development assistance

## 💻 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/MrAtharvaB/MiniTodoApp.git
   ```

2. Open the project folder:
   cd MiniTodoApp

3. Open `index.html` in your web browser.

No additional dependencies or installation are required.
